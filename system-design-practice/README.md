# System Design Practice

A structured collection of system-design notes and small architecture exercises for software-engineering interview preparation.

## Topics
- Scalability
- Load balancing
- Caching
- Databases
- Replication
- Sharding
- Message queues
- Rate limiting
- API design
- Observability
- Reliability

## Suggested study order
1. Requirements and capacity estimation
2. API and data modeling
3. High-level architecture
4. Database selection
5. Caching
6. Scaling and reliability
7. Security
8. Monitoring and trade-offs

## Design exercises
- URL Shortener
- Job Application Tracker
- Chat Application
- File Storage System
- Notification Service
- Rate Limiter

Each exercise should document requirements, architecture, APIs, data model, bottlenecks, scaling strategy, and trade-offs.
