# Database Design

## Relational database

Useful when:
- Relationships matter
- Transactions are important
- Strong consistency is required

Examples:
- PostgreSQL
- MySQL

## NoSQL database

Useful for certain high-scale or flexible-schema workloads.

Examples:
- DynamoDB
- MongoDB
- Cassandra

## Questions
- Read/write ratio?
- Data size?
- Query patterns?
- Consistency requirements?
- Transaction requirements?
- Growth rate?
